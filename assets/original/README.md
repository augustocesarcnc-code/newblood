# Bloodmoon transformation concept atlas

Original image generated for Bloodmoon during this session. It is not a downloaded Flare or OpenGameArt asset. The original generated file is preserved unchanged as transformation-atlas.png.

transformation-frames.json records crop rectangles for eight directional standing poses of the werewolf and eight of the vampire lord. The poses follow S, SW, W, NW, N, NE, E, SE. Browser rendering crops the atlas at runtime; no edited raster version is distributed.

These directional concept sprites are used for idle poses only. Locomotion now uses eight dedicated generated atlases under assets/animations, with separate walk/run cycles and eight frames in all eight directions. Human movement uses the eight-direction Flare run cycle at different walk/run playback rates.
