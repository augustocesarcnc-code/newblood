# Human design reference

`human-design-reference.png` is generated concept art for Bloodmoon: hunter,
human vampire and human werewolf, left to right. It is a costume and silhouette
reference, not a production sprite sheet or an animation atlas. It is not used
as a replacement for the playable layered humans.

The playable revision keeps the Flare source PNGs unchanged under their existing
CC BY-SA 3.0 attribution. Runtime changes enlarge each head around its per-frame
neck pivot, shorten silhouettes and adjust class clothing colors. Trousers and
boots are starter clothing layers and grant no equipment statistics. All equipment
continues to use the same body transform. Walking and running still share the
existing movement poses at different cadences; no new hand-drawn cycles are claimed.
