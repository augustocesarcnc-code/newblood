# ECLIPSE — DIREÇÃO VISUAL E TÉCNICA DEFINITIVA

Este documento substitui as orientações visuais anteriores que estejam em conflito com ele.

O projeto ECLIPSE deve seguir esta direção daqui para frente.

O objetivo é criar um MMORPG 2D/2.5D sombrio, gótico e adulto, com foco em:

- Vampiros
- Lobisomens
- Caçadores
- criaturas sobrenaturais
- cidades góticas
- florestas escuras
- catacumbas
- ruínas
- castelos
- cemitérios
- vilarejos
- cavernas
- masmorras

A identidade deve combinar características encontradas em jogos clássicos como:

- Ultima Online
- Diablo II
- Ragnarok Online
- MMORPGs isométricos clássicos
- action RPGs dark fantasy em pixel art

Essas referências servem como DIREÇÃO.

NÃO copiar diretamente personagens, mapas, HUDs ou assets protegidos desses jogos.

Criar identidade própria para ECLIPSE.

---

# 1. REGRA MAIS IMPORTANTE

AS SPRITES HUMANAS ATUAIS DO JOGO ESTÃO REPROVADAS.

Os personagens atuais possuem:

- cabeça grande
- corpo curto
- aparência chibi
- pouca definição
- pouca diferença entre NPCs
- silhueta genérica
- aparência de placeholder

NÃO tente corrigir essas sprites.

NÃO tente apenas diminuir a cabeça.

NÃO tente apenas aumentar as pernas.

NÃO tente colocar roupas novas sobre o mesmo corpo.

SUBSTITUA O PADRÃO VISUAL.

Os arquivos antigos podem ser arquivados para rollback, mas não devem servir como base visual principal.

---

# 2. CONCEITO VISUAL DO ECLIPSE

A combinação desejada é:

ULTIMA ONLINE

Para:

- escala do personagem dentro do mundo
- sensação de MMORPG
- muitos NPCs/jogadores ocupando o mesmo ambiente
- leitura clara de equipamentos
- exploração com câmera relativamente aberta
- mundo persistente

DIABLO II

Para:

- atmosfera
- iluminação
- contraste
- sombras
- ambientes decadentes
- fogo
- tochas
- gótico
- horror
- interface ornamental
- inventário
- sensação pesada de dark fantasy

RAGNAROK ONLINE

Somente para:

- organização de sprites
- fluidez das animações
- leitura das classes
- equipamentos
- movimentação multidirecional

NÃO utilizar:

- proporção chibi
- estética infantil
- visual anime exagerado

ECLIPSE deve possuir identidade própria.

---

# 3. CÂMERA

O jogo continua sendo 2D.

Utilizar:

VISÃO 3/4 / ISOMÉTRICA LEVE.

O mundo deve transmitir profundidade mesmo utilizando sprites 2D.

O jogador deve conseguir enxergar uma área razoavelmente grande ao redor.

Evitar câmera extremamente aproximada.

Personagens não devem ocupar uma parte exagerada da tela.

Referência conceitual:

Ultima Online + Diablo II.

---

# 4. ESCALA DOS PERSONAGENS

Os personagens devem parecer humanos dentro daquele ambiente.

A escala precisa funcionar corretamente em relação a:

- portas
- janelas
- mesas
- cadeiras
- casas
- árvores
- postes
- pontes
- bancos
- baús
- monstros

O personagem deve ser relativamente pequeno na composição geral do mapa.

Mas ainda precisa possuir detalhes suficientes para reconhecer:

- roupa
- arma
- classe
- silhueta

---

# 5. PROPORÇÃO HUMANA

Personagens humanos devem possuir proporção adulta.

Objetivo aproximado:

6 a 7 cabeças de altura.

Cabeça pequena em relação ao corpo.

Características:

- ombros definidos
- pescoço
- tronco proporcional
- cintura
- braços naturais
- pernas longas
- botas
- mãos legíveis
- postura adulta

NÃO criar:

- cabeça gigante
- pernas minúsculas
- braços curtos
- corpo infantil
- corpo redondo
- aparência Funko
- aparência mobile
- aparência RPG Maker genérica

---

# 6. ESTILO DAS SPRITES

Utilizar pixel art ou pixel art detalhada.

Não precisa ser hiper-realista.

Mas precisa transmitir:

- peso
- anatomia
- material
- roupa
- arma
- iluminação

Priorizar:

SILHUETA.

A sprite deve continuar reconhecível mesmo pequena.

---

# 7. PERSONAGEM PRINCIPAL

O personagem do jogador deve possuir qualidade superior aos NPCs comuns.

Cada classe precisa possuir uma silhueta própria.

Classes iniciais:

CAÇADOR

VAMPIRO

LOBISOMEM

---

# 8. CAÇADOR

O Caçador será o PRIMEIRO personagem utilizado para validar todo o novo padrão visual.

Características:

- humano adulto
- aparência séria
- corpo proporcional
- sobretudo
- couro
- botas
- cintos
- luvas
- acessórios de caça
- armas
- detalhes metálicos
- possível chapéu
- silhueta forte

Inspirar-se conceitualmente em caçadores de criaturas sobrenaturais.

O personagem deve transmitir:

EXPERIÊNCIA.

PERIGO.

DISCIPLINA.

---

# 9. VAMPIRO

O Vampiro humano deve possuir aparência:

- elegante
- sombria
- aristocrática
- ameaçadora

Possíveis elementos:

- sobretudo
- capa
- colete
- camisa
- armadura leve
- botas
- luvas
- ornamentos
- joias discretas
- gola alta

Paleta:

- preto
- vinho
- vermelho escuro
- prata
- dourado envelhecido

A silhueta do Vampiro deve ser diferente da do Caçador.

---

# 10. LOBISOMEM HUMANO

A forma humana pode utilizar equipamentos normalmente.

Pode possuir:

- roupas
- armaduras
- armas
- botas
- acessórios

Porém, deve existir alguma personalidade visual que diferencie a classe.

---

# 11. LOBISOMEM TRANSFORMADO

Quando transformado:

NÃO utilizar equipamentos humanos sobrepostos.

A transformação troca completamente a aparência.

Utilizar uma SPRITE COMPLETA DO MONSTRO.

Características:

- significativamente maior que um humano
- braços longos
- mãos grandes
- garras
- cabeça lupina
- focinho
- presas
- pernas fortes
- postura inclinada
- aparência pesada
- musculatura
- silhueta agressiva

Evitar:

“humano normal com cabeça de lobo”.

O corpo inteiro precisa transmitir criatura.

# 28. PROFUNDIDADE

NA FRENTE de objetos.
